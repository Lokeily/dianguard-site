告警体验：不可能被忽略

普通通知会被免打扰、静音、锁屏挡下。地震预警利用 P 波先于 S 波到达的时间差，只有几秒到几十秒，任何一次「没看到」都可能是致命的。

强制全屏倒计时

达到阈值的预警会直接拉起全屏告警页，覆盖在锁屏之上并自动点亮屏幕，不依赖用户去下拉通知栏。

  • 锁屏之上直接弹出，无需解锁即可看到剩余秒数与避险提示。

  • 震中地名始终可见，全程不被其他文案替换，方便你判断这次到底发生在哪。

Ⅰ 红 · Ⅱ 橙 · Ⅲ 黄 · Ⅳ 蓝 四级预警

等级按你所在地的预估烈度（中国地震局官方标准）划分，决定告警页配色与语音内容；是否触发全屏，由预估烈度与你设定的阈值共同决定。

Ⅰ级 红色
预估烈度 ≥ 7°
灾害性。可能造成建筑损毁，请立即就近躲避、保护头部，震后有序撤离。
Ⅱ级 橙色
5° ≤ 预估烈度 < 7°
灾害性。可能造成物品倾倒、墙体开裂，请立即采取防护措施并准备避险。
Ⅲ级 黄色
3° ≤ 预估烈度 < 5°
告知性。室内物品可能轻微晃动，请提高警惕，远离玻璃、吊灯与高处物品。
Ⅳ级 蓝色
预估烈度 < 3°
告知性。多数人仅感轻微晃动或无明显感觉，留意后续信息即可。
等级由「本地烈度」决定，不是震级

一次远方的 6 级地震，你这里的预估烈度可能不到 2 度，只会进通知栏；一次近处的 4.5 级小震却可能触发全屏。阈值可在 3° / 2°（默认推荐）/ 4° 间切换：调高更安静，调低更灵敏。单源初报会被标记为 isPreliminary，禁止触发红色，防止误报。

两套分级标准并存：历史列表按震级着色（红 ≥6.0 / 橙 5.0–5.9 / 黄 3.0–4.9 / 蓝 <3.0），告诉你地震本身有多强；倒计时弹窗按你所在地的预估烈度着色（红 ≥7° / 橙 5–6° / 黄 3–4° / 蓝 <3°），告诉你该怎么避险。二者服务不同的认知目的，不可混用。

真实大陆预警语音，不是机器读数字

像消防警铃一样「听得懂、叫得醒」：告警音频全部采用真实的大陆地震预警录音，分段拼接播放，走闹钟音频通道，静音与免打扰下依然响。

Audio Pipeline

三段式播报

从收到预警到震动抵达，音频按三个阶段自动衔接，不需要你做任何操作。

  • STREAM_ALARM 通道：与闹钟同级，不受媒体音量与静音影响。
  • 逐字倒计时音频：10 / 9 / … / 1 为独立音频文件，每秒精确播放一个。
  • 分级短语：不同等级对应不同的提示语，蓝色偏安抚、红色偏紧急。
  • 震动同步：语音播报的同时触发震动，睡眠或嘈杂环境下也能感知。

EewFusion自研核心

EewFusion — 自研多源融合决策引擎

借鉴集成学习思想，每个数据源被视为独立「专家」。在 1.0–1.5s 动态融合窗口内收集多源报文后加权融合、震级校准与趋势融合，单源异常不会主导结果：

这是地震哨兵区别于「单源转发器」的核心能力，完全由作者自研：让多源相互印证，而非盲信单一来源。

  • 震级融合 + 校准：加权中位数更抗异常值；并按「源 × 震级桶」预训练修正，偏差钳制在 ±0.5 内。
  • 坐标选优：取权重最高源的原始坐标，严禁加权平均（避免物理意义错误）；并带坐标死区防抖。
  • 初报 / 终报双轨：多源一致→高置信触发；单源初报标记 isPreliminary 禁止触发红色；修正量 >±0.4 强制推送版本更新。
  • 趋势融合：按各源相对共识偏移量动态加权，捕捉震级 / 位置修正；单源伪造报文被中位数 + 置信度机制抑制。
  • 动态融合窗：1.0–1.5s 自适应——多源在线时自动缩短，单源时延长以积累证据。
  • 状态 TTL 淘汰：按事件版本隔离，30 分钟超时状态自动回收，杜绝内存泄漏（v1.3.2 修复）。

工程保障：动态融合窗 · 震级校准 · 趋势融合 · 坐标防抖 · 按版本隔离 · 状态 TTL 30min 淘汰 · 10 分钟跨源去重，确保不重复、不漏报。

EewFusion 为地震哨兵自研核心算法。仓库以 Apache-2.0 协议开源（UI / 解析 / 烈度衰减 / 告警 / 历史 / 证书固定 / 构建），其核心融合与 FusionCalibration 以 专有协议分发、不随仓库公开；仓库内含接口一致的精简兼容实现（ingest / forceFlush / FusionResult），便于审阅与二次开发。

可以调，也可以演练

预警是个平衡：太灵敏会疲劳，太保守会漏报。这些开关都交给你自己决定。

烈度阈值三档可调

2°（轻微有感，推荐）/ 3°（明显有感）/ 4°（强烈有感）。低于阈值仅通知栏提示，从源头避免告警疲劳。

它向你要哪些权限，为什么

每一项权限都直接对应一个具体功能。缺少标为「必需」的权限，预警将无法正常工作。

定位必需

计算你与震中的距离，据此估算本地烈度与横波到达倒计时。坐标仅保存在本机。

通知必需

展示常驻的前台服务通知（保证不被系统杀死），以及低于阈值的远震提醒。

悬浮窗 / 后台弹出必需

让全屏告警页能在应用未打开、甚至锁屏状态下强制弹出。这是「不可能被忽略」的前提。

忽略电池优化必需

阻止系统在息屏后冻结长连接。不豁免的话，你很可能在最需要的时候恰好是断线状态。

震动建议

告警时同步震动。睡眠中或嘈杂环境下，震动往往比声音更容易把人唤醒。

网络必需

维持 WebSocket 长连接接收预警报文，以及拉取历史地震目录与中文地名。

别忘了厂商白名单

小米、华为、OPPO、vivo、荣耀等系统会额外限制后台。请在系统设置中把地震哨兵加入自启动白名单并设为无限制运行，否则前面所有权限都可能白给。
