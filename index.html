核心功能

📢

全屏倒计时告警

S 波到达前强制全屏弹出，锁屏之上、亮屏、横竖屏自适应，蓝/黄/橙/红四级预警 + 真实大陆预警语音播报。

🌐

多源去单点

同时订阅 Wolfx、BeeCLD·2v8 等相互独立的主机，任一可达即触发；FAN Studio 配置密钥后自动启用。

🎚️

烈度阈值可调

2°/3°/4° 三档阈值，低于阈值仅通知栏提示，避免告警疲劳。3° 为推荐默认值。

🧪

模拟预警

以手机定位周边真实城市为震中，随机方向与 ETA，拉起与真实预警完全一致的全屏页面，用于科普自测。

📜

地震历史记录

抓取中国地震台网速报目录，最近 50 条，含中文地名、震级、深度与发震时刻，按等级色展示。

🌙

深色 OLED 省电

跟随系统 / 浅色 / 深色（#000000 纯黑）三档，AMOLED 黑色像素直接熄灭，防烧屏。

真实大陆预警语音

告警语音全部采用真实大陆预警录音，不使用 TTS 读数字，全链路走 STREAM_ALARM，锁屏/静音下最大音量。

  • 短语循环「有感地震，请勿惊慌」等分级短语，倒计时前循环播放。
  • 逐字倒计时将「10 秒倒计时」拆成 10 / 9 / … / 1 的独立音频，每秒播一个。
  • 警报倒计时归零后循环播放，直到你点击「我已安全」。

安装前必看

1

下载 APK

从 GitHub Release 下载 Dianguard-v1.2.0-release.apk，体积约 16 MB。

2

允许安装未知应用

首次安装时按系统提示授权浏览器/文件管理器「安装未知应用」权限。

3

开启必要权限

定位、通知、悬浮窗、忽略电池优化，按引导页逐项开启，否则无法后台监听。

4

加入厂商白名单

小米/华为/OPPO/vivo 等需在系统设置中将本应用加入自启动 + 电池优化豁免。
