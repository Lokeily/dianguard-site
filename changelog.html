v1.3.2最新 2026-08-05

融合引擎 v2.4 完整版 · 与 v1.3.1 的关键变化

🧠 EewFusion 融合算法升级
  • 加权中位数融合：对五路实时源（CENC / SC / CQ / CWA 经 Wolfx 镜像、ICL 独立域名）做加权中位数收敛，抑制单源跳变。
  • 动态融合窗：融合窗口在 1.0–1.5 秒之间自适应，源越多越短、源越少越长。
  • 震级校准：基于历史偏差对每路震级做 ±0.5 自动修正，收敛后取中位估计。
  • 趋势融合：捕捉震级随时间动态修正的轨迹，而非只取单帧快照。
  • 初报 / 终报双轨：先发初步结论（`isPreliminary`），修正量大于 ±0.4 时强制推送新版本，终报收敛后锁定。
  • 状态 TTL 淘汰：事件状态 30 分钟未更新即淘汰，修复长时间运行的内存泄漏。
📡 数据来源收敛
  • 实时源收敛为五路：CENC / SC / CQ / CWA（Wolfx 单一网关镜像）+ ICL（完全独立官方域名）。
  • 用户自建源（BeeCLD · 2v8 · FAN Studio）自 v1.3.2 起不再内置，需用户自行接入。
📋 工程改进
  • 融合核心以 Apache-2.0 开放 `ingest` / `forceFlush` / `FusionResult` 接口，自研调权与校准逻辑以专有许可保护。

v1.2.0 2026-08-03

与 v1.1.0 的关键变化

🚨 告警系统重构（核心安全改进）
  • 告警阈值改为本地烈度判定：不再用震级一刀切，改为按震中距+深度+震级估算用户所在地烈度（汪素云等2000短轴衰减模型），避免远震误报。
  • 四级预警配色标准化：红/橙/黄/蓝严格对应震级分级，全软件统一配色（AlertActivity/HistoryFragment/TestAlarmActivity）。
  • 三段式真实语音播报：采用真实大陆预警录音（非TTS），短语循环 → 逐秒倒计时 → 警报循环，全程走ALARM流、锁屏/静音下最大音量。
📡 数据源全面升级
  • 新增 BeeCLD·2v8 独立主机（api.2v8.cn/ws/cea）：中国地震预警网CEA国家级秒级预警源，与Wolfx完全独立，去单点设计。
  • FAN Studio 鉴权握手代码已就绪（需用户配置API密钥后启用）
  • 备用探测源增强：USGS + Wolfx HTTP + EMSC 三级兜底，主链路全断时自动激活。
📋 历史记录大幅改进
  • 主源改为中国地震台网速报目录（api.wolfx.jp/cenc_eqlist.json），中文地名/震级/深度齐全
  • USGS FDSN + EMSC FDSN 双兜底
  • BigDataCloud 免密钥逆地理编码 + 内置省级边界表
  • 顶部特色卡片 + 等级色列表，标注来源与本地预估烈度
🎨 界面与体验
  • 深色模式默认开启（OLED纯黑省电，适配常亮旧手机）
  • 设置页参考位置只显示中文地名（Geocoder → BigDataCloud → 省级表三级兜底），绝不显示裸经纬度
  • 模拟预警以周边真实城市为震中，完整模拟全屏告警流程
  • 告警页排版优化：大数字倒计时、「秒」紧随数字、归零显示「地震波已抵达」
  • 全局字体统一为简体中文（内嵌Noto Sans SC）
  • 繁体地名自动转简体（离线字符映射表）
🔧 工程改进
  • 核心算法抽为顶层纯函数，56个单元测试全部通过
  • 多源连接管理重构（EewConnectionManager/EewAlertManager职责分离）
  • WakeLock无条件续期（消除4小时失效窗口）
  • 启动冷静期15秒（防止BeeCLD补推历史EEW误弹告警）
  • 返回键拦截（告警页只能点「我已安全」解除）
  • 崩溃日志坐标自动脱敏
🔒 安全增强
  • BEECLD_TOKEN从源码硬编码迁移到BuildConfig注入
  • Doze休眠白名单引导
  • 历史记录SP写入容错
